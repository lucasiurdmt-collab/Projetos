# Sistema de Sorteio ao Vivo (vMix, Telão LED & Inscrição Mobile) 🎉

Sistema profissional completo para eventos com mais de 10.000 pessoas, dividido em:
1. **Página de Inscrição Mobile (QR Code do Público)**
2. **Mesa de Controle (Backstage / Operador)**
3. **Telão de Exibição (vMix / Painel de LED)**

---

## 🔗 Links Oficiais no GitHub Pages

### 1. 📱 Formulário de Inscrição do Público (QR Code)
👉 `https://lucasiurdmt-collab.github.io/Projetos/cadastro.html`
- Visual incrível para celular no mesmo padrão visual da Caminhada do Amor.
- Botão oficial para abrir o canal do YouTube.
- Campos para Nome Completo, WhatsApp e confirmação.
- Envia os dados direto para o **Google Forms / Google Planilhas** por trás dos panos, aproveitando a infraestrutura do Google para suportar picos de 10.000+ participantes simultâneos sem sobrecarregar o site!

### 2. 🎛️ Mesa de Controle (Backstage / Equipe da Produção)
👉 `https://lucasiurdmt-collab.github.io/Projetos/`
- Onde a equipe carrega a planilha gerada pelo Forms ou cola os nomes.
- Elimina duplicados automaticamente.
- Botão Mestre: **"DISPARAR SORTEIO NO TELÃO!"**
- Monitoramento de sinal em tempo real (mostra se o vMix/Telão está ativo).

### 3. 🖥️ Telão de Exibição (vMix / Painel de LED)
👉 `https://lucasiurdmt-collab.github.io/Projetos/telao.html`
- Para projetor, painel de LED ou Web Browser Input no vMix.
- Efeito de roleta desacelerando com suspense, confetes e sons sintetizados.
- Versão com fundo transparente para overlay de câmera:  
  `https://lucasiurdmt-collab.github.io/Projetos/telao.html?transparent=true`
